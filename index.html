Website Profil Kelompok

Proyek Kolaborasi Git dan GitHub

Tentang Proyek

Website ini dibuat untuk memenuhi tugas mata kuliah Rekayasa Perangkat Lunak mengenai penggunaan Git dan GitHub dalam pengembangan perangkat lunak secara kolaboratif.

Anggota Kelompok

  1. Rozaan Nazmi Daffa Ghifari
  2. Kaisyar Fauzi Ali Baskara

Tujuan Proyek

Proyek ini bertujuan untuk mempelajari pengelolaan versi kode, penggunaan branch untuk mengembangkan fitur, serta proses pemeriksaan dan penggabungan perubahan melalui Pull Request.

Teknologi yang Digunakan

  • HTML untuk membuat struktur halaman.
  • CSS untuk mengatur tampilan website.
  • Git untuk mencatat perubahan kode.
  • GitHub untuk menyimpan repository dan mendukung kolaborasi.
