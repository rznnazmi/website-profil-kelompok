# Website Profil Kelompok

## Deskripsi

Website Profil Kelompok merupakan proyek sederhana berbasis HTML dan CSS yang dibuat untuk memenuhi tugas kolaborasi Git dan GitHub pada mata kuliah Rekayasa Perangkat Lunak.

## Tujuan

Proyek ini bertujuan untuk mempelajari penggunaan Git dan GitHub dalam pengembangan perangkat lunak secara kolaboratif.

## Teknologi yang Digunakan

* HTML
* CSS
* Git
* GitHub

## Fitur Website

* Menampilkan informasi proyek.
* Menampilkan nama anggota kelompok.
* Menampilkan tujuan pembuatan proyek.
